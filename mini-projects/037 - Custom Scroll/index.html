اصلاً چرا برنامه‌نویسی؟

از سایت‌هایی که هر روز باز می‌کنی تا بازی‌ها و برنامه‌هایی که با گوشی استفاده می‌کنی، همه با کمک برنامه‌نویسی ساخته شدن.

شاید برات جالب باشه بدونی که تو هم می‌تونی چنین چیزهایی بسازی. برای این کار فقط باید قدم‌به‌قدم یاد بگیری.

01

کامپیوتر چیه؟

کامپیوتر دستگاهیه که اطلاعات رو دریافت می‌کنه، روی اون‌ها کار انجام می‌ده و نتیجه رو به ما نشون می‌ده.

مثلاً وقتی با ماشین‌حساب گوشی عدد ۵ و ۳ رو جمع می‌کنی، گوشی نتیجه ۸ رو بهت نشون می‌ده.

یک مثال ساده

اطلاعات ورودی: ۵ و ۳

نتیجه: ۸

برای شروع برنامه‌نویسی لازم نیست بدونی قطعات داخلی کامپیوتر چطور کار می‌کنن.

02

برنامه و کد چه فرقی دارن؟

برنامه مجموعه‌ای از دستورهاست که به کامپیوتر می‌گه چطور یک کار رو انجام بده.

مثلاً ماشین‌حساب، بازی، مرورگر اینترنت و برنامه‌های پیام‌رسان همگی برنامه هستن.

اما کد همون دستورهاییه که برنامه‌نویس می‌نویسه تا کامپیوتر بتونه اون‌ها رو اجرا کنه.

برنامه: چیزی که ساخته می‌شه.

کد: دستورهایی که برای ساخت و اجرای اون نوشته می‌شن.

03

برنامه‌نویسی یعنی چی؟

برنامه‌نویسی یعنی یک مسئله رو بررسی کنیم، راه‌حلش رو پیدا کنیم و اون رو به دستورهایی تبدیل کنیم که کامپیوتر بتونه اجراشون کنه.

فرض کن می‌خوای یک ماشین‌حساب ساده بسازی. برای این کار باید به کامپیوتر بگی:

  1. عدد اول رو از کاربر دریافت کن.
  2. عدد دوم رو دریافت کن.
  3. این دو عدد رو با هم جمع کن.
  4. نتیجه رو به کاربر نشون بده.
نکته مهم

برنامه‌نویسی فقط تایپ کردن کد نیست؛ بخش مهمش اینه که یاد بگیری چطور مسئله‌ها رو به قدم‌های کوچک‌تر تقسیم کنی و براشون راه‌حل پیدا کنی.

04

زبان برنامه‌نویسی چیه؟

برای نوشتن دستورها و ساخت برنامه‌ها از زبان‌های برنامه‌نویسی استفاده می‌کنیم.

هر زبان کاربردهای خودش رو داره. چند نمونه معروف رو ببین:

Python

برای ساخت برنامه‌ها، کار با اطلاعات و هوش مصنوعی.

JavaScript

برای ساخت سایت‌های تعاملی و امکانات صفحات وب.

Java

برای ساخت انواع نرم‌افزارها و برنامه‌های مختلف.

لازم نیست همه زبان‌ها رو یاد بگیری. انتخاب زبان به هدفی که داری بستگی داره.

05

آیا برنامه‌نویسی سخته؟

یادگیری برنامه‌نویسی همیشه آسون نیست، اما غیرممکن هم نیست.

ممکنه اوایل با خطاهایی روبه‌رو بشی که دلیلشون رو متوجه نشی. این اتفاق کاملاً طبیعیه.

اشتباه کردن بخشی از یادگیریه. مهم اینه که از خطاها درس بگیری و به تمرین ادامه بدی.

برای شروع هم به ریاضیات پیشرفته یا مدرک دانشگاهی نیاز نداری.

06

از کجا برنامه‌نویسی رو شروع کنیم؟

حالا که با مفاهیم اولیه آشنا شدی، وقتشه اولین قدمت رو برداری.

۱

یک هدف مشخص کن

دوست داری سایت بسازی، برنامه کامپیوتری بنویسی یا وارد دنیای هوش مصنوعی بشی؟

۲

یک زبان انتخاب کن

برای شروع می‌تونی Python رو انتخاب کنی و مفاهیم اولیه برنامه‌نویسی رو باهاش یاد بگیری.

۳

تمرین کن

فقط ویدئو نبین؛ خودت کد بنویس، اجراش کن و نتیجه رو بررسی کن.

۴

پروژه‌های کوچک بساز

با یک ماشین‌حساب ساده یا بازی حدس عدد شروع کن. لازم نیست از همون اول پروژه بزرگی بسازی.
